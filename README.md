# Agnieszka Bola Portfolio

A one-page portfolio for a Tech Lead, Engineering Manager, and Senior Software Engineer.

## Contact links

The email link is in `components/Contact.tsx`. LinkedIn destinations for the Contact and Experience sections are in `lib/translations.ts`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

From the project directory, deploy a preview with:

```bash
npx vercel
```

Deploy to production with:

```bash
npx vercel --prod
```

Vercel detects Next.js and configures the build automatically. A personal portfolio can be hosted on Vercel's free Hobby plan, subject to its current plan limits.
